# 飞夺泸定桥 · V3.1

运行 `Windows/FeiDuo_LudingBridge_V3_1.exe`。资源、对白、战斗配乐与音效已内嵌，运行游戏不需要联网或安装 Python。

本次针对攀索僵硬、队友排队、战场缺少交火与配乐平淡进行调整：

- 攀索改为随实际位移推进的交替抓握；抓住的手短暂固定在世界坐标，另一只手换抓。双脚交替勾住下方铁索，并有轻微身体重心变化；停下时不会继续原地蹬腿。
- 桥上采用八人循环波次，不同速度分批快跑。未修好的通道前会分散在安全区域，部分战友停下瞄准掩护，其余继续推进。窄木板与铁索处保留合理间隔。
- 两岸新增四个 NPC 炮组，自动装填、开火、后坐，炮弹沿弧线飞行，落点产生爆炸、尘土或水花。主角不用操作火炮。
- 增加两岸前景步兵交替移动与射击、远景行军兵形，以及桥头火焰和烟尘。前景额外使用 16 名骨骼角色，远景使用 72 个低成本兵形；远景兵形不是完整可交互 AI。
- 新写行进、冲锋、攀索危机和胜利四段配乐，使用铜管、弦乐、军鼓、定音鼓及镲。攀索会切换到危机段落，对白时自动降低配乐。保留上版三种男性对白声线。

WASD 移动，Shift 奔跑，E 交互或放板，右键放下搬板并瞄准，左键射击；松开右键后到板端 E 续搬。F 观察，Q 发信号，Tab 展开教程，Esc 暂停。攀索时 W/S 前后、A/D 调平衡。

炮击是战场演出，不会随机炸毁必需桥板或直接结算玩家炮伤。主线的步枪威胁、战友受击和坠河逻辑仍然存在。人物、炮组部署、兵力数量及 78 米跨度均为玩法改编，不作为具体历史部署与伤亡数量的复原。

电影资料参考：[央视电影《万水千山》](https://tv.cctv.com/2014/06/06/VIDE1402018927787623.shtml)、[央视《百年瞬间丨红军飞夺泸定桥》](https://m.news.cctv.com/2021/05/23/ARTIoHVnbWpBxPp2OBKEL3UR210523.shtml)。本版的编配与旋律为原创，并未宣称逐轨还原电影原配乐；电影音视频没有作为游戏素材打包。

音乐使用 GeneralUser GS 2.0.3 乐器音色渲染，音色作者为 S. Christian Collins；授权允许自由创作和发布音乐，许可证见 `licenses/GeneralUser_GS_License.txt`。再生成脚本为 `tools/compose_battle_score.py`，需另行下载该 SoundFont，安装 `numpy tinysoundfont` 后传入 `--soundfont` 参数。炮声与爆炸声是脚本合成的原创音效。

Godot 4.6 默认入口仍为 `game/v2/main.tscn`，目录名称为兼容旧工程保留。新增模块是 `game/v31/battlefield.gd`；攀索接触检查与战场检查位于 `tests/v31/`。影片为交付程序的实际输入回放，含辅助镜头朝向及炮组展示镜头；主线任务、人物位置和敌人血量没有由回放器直接设成完成。
