V3.0 expressive Chinese speech provenance

The 50 released WAV clips are generated locally with Qwen3-TTS-12Hz-1.7B-CustomVoice (Apache-2.0). The game plays included 16-bit PCM files offline; the generation model and Python runtime are not distributed in the game.

Official repository: https://github.com/QwenLM/Qwen3-TTS
Official model: https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice
License copy: Qwen3_TTS_Apache_2_0.txt

Documented male cast: Captain Zhou = Uncle_Fu; Linchuan = Dylan; Amu = Eric. Non-character explanations use Uncle_Fu with calm instructional direction.

Each manifest entry records the exact subtitle text, any spoken-text normalization, speaker, semantic/emotional instruction, generation signature, duration, sample rate and WAV SHA-256. Commands, warnings, cooperative responses, relief and grief use different natural-language directions. Internal pauses are generated by the model; only excessive outer silence is trimmed. Output peaks are normalized to 0.89.

These are synthetic performances, not hired actors or the developer's human voice. No real person's voice was cloned or private recording uploaded. Emotional direction is not model training or autonomous learning. Acting quality remains subjective.

Regenerate with tools/Generate_Expressive_Voices.py and the separately downloaded 1.7B CustomVoice model. The 0.6B variant does not support instruct control and is not used. This release uses CUDA bfloat16 and SDPA on an RTX 4060 Laptop GPU. Some clips were generated in pairs through the official batched API with the same directions and post-processing. Manifest hashes identify exact output files.

V2.2 neural Chinese speech provenance

All 47 in-game WAV files were generated locally with Kokoro-82M-v1.1-zh (int8 ONNX conversion distributed by sherpa-onnx). The model and its voice data are licensed Apache-2.0. A copy of the model LICENSE is in Kokoro_Apache_2_0.txt.

Official model: https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh
Runtime/conversion documentation: https://k2-fsa.github.io/sherpa/onnx/tts/pretrained_models/kokoro.html
Download: https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-int8-multi-lang-v1_1.tar.bz2

Cast (all officially documented Chinese male voices):
Captain Zhou: sid 58 / zm_009 / speed 0.96
Linchuan: sid 61 / zm_012 / speed 1.00
Amu: sid 65 / zm_016 / speed 1.03
Neutral record/hint narrator: sid 61 / zm_012

These are three independent neural speaker embeddings, not pitch-shifted variants of the Windows SAPI voice. Audio is synthesized speech, not a recording by hired human actors. No real person's voice was cloned or uploaded. The model is needed only for regeneration; the released game plays the included WAV files offline.

Regenerate with tools/Generate_Neural_Voices.py and a downloaded model directory. manifest.json contains exact subtitle text, spoken text where normalization is needed, speaker identity, duration and file SHA-256. The old System.Speech regeneration script is retained only as a legacy reference and is not used by this release.
