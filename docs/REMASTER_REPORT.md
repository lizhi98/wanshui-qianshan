# 《万水千山：战火中的木板》重制交付报告

本版在原Godot工程上完成自然人物、制服、混合动画、正式交谈、连续章节、较长桥梁和2026观察尾声。默认入口`game/remaster/main.tscn`，旧场景和原机制测试保留在源工程中。

## 本次完成的主要变化

三个自然比例人物采用MPFB输出，分别为林川1.72m、阿木1.68m和周班长1.77m；53根骨骼和43段免费动作重定向。制服使用独立服装网格，口袋、领片、门襟、背包与帽子为真实几何。帽子已改为连续帽体和帽檐，按实际头骨定位，100%绑定Head，修正前后错位、悬空和头发/额头穿模。

三人不再同步使用同一段讲话动作。林川动作较克制，阿木较活跃并偶尔扶肩带，周班长采用较慢的单手说明和指向。说话者与听者使用不同身体语言；含指向、说明、担忧、回忆、安抚与坚定姿态，调整手指松紧、呼吸、动画相位、眨眼和目光过渡。协作固定横档时，林川保持握点，阿木双手交替绕绳与收紧。实际观感可查看图集和运行视频。

Dialogue Manager 4.1.0实际解析原创对白、分支和流程；展示层提供打字、手动、自动、跳过与输入恢复。镜头包含双人、中景、过肩、特写、桥梁建立和结尾拉远等组合。

序章、第一至第三章与现代尾声连续推进。战斗保留步枪射线、装填、补给和掩体；固定横档和协作铺板为不同操作；铺板后开启真实碰撞；长桥缺口需要抓索并调平衡，之后等候战友会合。2026尾声使用三个虚拟观察点逐层显示底索、扶索和桥面，支持环绕缩放、历史阅读及对照。

环境使用连续地形、PBR地面/木材/岩石、扫描岩石及减面松树，桥梁有9根底索与4根扶索。默认Forward+，并提供性能画质及Compatibility启动方式。原创合成音乐分探索、战斗、攀索、结尾与现代篇切换；没有真人配音。

## 验证结果

102项自动断言及10份剧情文件编译遍历通过。三人帽体几何与转头绑定检查通过。默认自动阅读的确定路线回放为12分50秒。Windows实际录制的完整输入回放0失败。最终普通渲染回放与性能口径以`Test_Records/测试报告.md`及最新原始日志为准，录制帧率不充作性能基准。

自动输入回放使用实际控制器、交互、战斗和攀索逻辑，精确瞄准由脚本辅助。摆位截图、自动回放和独立真人验收分别记录；尚未完成独立真人全程试玩与低配设备全流程复测。

## 历史与艺术化边界

1935年5月29日、22名突击队员与一边铺板一边前进的叙述参考中国军网[《飞夺泸定桥场景》](https://photo.81.cn/zhuanti/2016-09/21/content_7270392.htm)；13根铁索与史实桥长约103米参考[泸定桥景区官方介绍](https://www.scldq.cn/about.html)。游戏采用78米艺术化可玩跨度、放大链环、两处火力点和简化缺板路线，不是历史战斗或工程结构的精确复原。

三位主角是虚构普通战士，不替代真实22名突击队员。2026尾声为教学观察模拟，未使用真实测绘数据。1935至2026相隔91年；篇名“九十年后的回答”为文学表达，游戏档案已说明。
