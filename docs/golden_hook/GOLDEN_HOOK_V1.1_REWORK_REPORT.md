## 已修改的画面与人物

- 地形：共享不规则岸线驱动水面、岸坡和合法落点；增加连续起伏、PBR 草地/湿泥变化，区分路径、营地、裸泥、浅水与深沼。近远地形以逐米共享边缘顶点连接，修复远景漏白线。
- 植被/环境：采用合法 CC0 草、灌木、岩石和 HDRI 资源，按生境与踩踏分区布置并做近/中/远 LOD；增加原创曲茎折叶芦苇，不以单纯翻倍均匀撒草代替升级。
- 营地：新增布顶缝线、绳索、带扣布包、粮袋、卷毯、搪瓷锅、空心木勺。修复双面布料、打开炊锅锅盖、把加热针移到火边，使鱼汤、搅拌与金属近景可见。
- 人物：小梁/小石沿用成熟人物基底；阿青在 Blender 中独立修改下颌、颧骨、鼻部、帽形、服装与携带物；老班长修改面部形态、灰发/灰眉与老化材质。四人有独立轮廓/体态/服装差异，但不能宣称已有扫描级写实面容。

## 动作与接触

复用最新第二关的完整 Walk/Jog 与脚底接触规范；NPC 单物理根节点、加减速、有限转身，修复斜坡切向速度。坐下/起身采用 Sitting_Enter/Idle/Exit，起身结束后再走路。手掌/手指 CCD 对齐钓竿、碗、针/钩、木勺和布包；退出互动清空手部约束。针部实际指尖距离在专项检查中约 3.5 毫米。

老班长从受控倒下进入双臂收拢的最终姿态，头部卷毯支撑，牺牲后停止待机、呼吸和头部动作。读档直接恢复最终姿态，队友布局保护身体位置。正面、侧面、俯视图片和动作测试视频独立提供。手指细微握持与部分近景仍需动画师精修，没有把接触误差小等同于自然表演完全合格。

## 配音与配乐

真正使用五种独立声线：老班长 Yunjian、小梁 Yunxi、小石 Yunxia、阿青 Yunyang、旁白 Xiaoxiao。不是同一 SAPI 声音改语速；81 个对白 ID 和离线文件机制保持，十五句样本与五组试听已交。尚无独立真人听审签核，Edge 韵律参数也不等同于情绪表演引擎，临终/哽咽等目标没有冒充达标。详见 VOICE_CASTING_REPORT.md。

配乐重编为六段原创 MIDI/采样乐器曲，83–124 秒/段，共 581.65 秒，分 shortage/hope/fishing/warm/urgent/memory。秘密和临终使用音乐静默，保存鱼钩渐入回忆主题。唯一 BGM 播放器平滑切换、对白压低音乐、池塘/营火空间声源和三个独立音量档位已经接入。完整 Windows 实际混音已录制并另导音轨；主观音乐与混音验收待人审听，详见 MUSIC_MANIFEST.md 和 AUDIO_NOTES.md。
