# V1.1 解锁后的桌面键鼠补测

日期：2026-11-01。执行方式：Codex 使用 computer-use / Sky 操作实际导出的 Windows 程序。电脑已解锁；没有操作登录界面。本记录属于桌面自动化验收，不是独立真人盲测或人工听审。

## 已实际观察

- 鼠标依次进入第一、第二、第三关，再返回统一章节菜单，入口与返回可用。
- 音乐 85%→100% 时音效、配音不变；音效 85%→100% 时配音不变；配音 100%→0% 时其他分项不变。退出重启后，三个分项和性能模式被保留。

- 双行开场目标与物品栏现在位于同一个完整背景框中，不再露出框外。

## 本轮发现与修改

按键诊断只记录游戏窗口自己的事件：桌面工具发出的 Escape 逻辑键为 4194305、W 为 87，但二者物理键码都为 4194313。旧热键只接受物理键码，导致该桌面输入方式不能暂停/交互。现保留原物理键位，并支持正确的逻辑按键；没有修改 fishing_model.gd 或角色物理运动规则。

任务框原本与文字分别放置，固定高度 145，双行目标使物品栏越界。现将文字 VBox 放入 PanelContainer，使背景按内容自动调整。新增检查在 1280×720 和 1920×1080 验证包围关系。

新增 12 条回归覆盖逻辑/物理 Escape、带保持时长的逻辑 W 移动与释放、逻辑 E 的实际物资检查事务、Space 过早提竿失败、E 重试、Q 收竿及任务框边界，全部通过。RED 与 GREEN 日志随附。章节菜单/声音设置代码在本轮输入修复前后未变；修正版另行执行整包导航和完整通关回放。

## 验收边界与清理

Sky 的 press_key 没有持续按住参数，单次瞬时 W 不能作为持续行走验收；本项由有保持时长的场景检查与完整输入回放覆盖，不把桌面短按写作已经完成持续移动实测。独立真人首次游玩、自然中文情绪和配乐艺术质量的人工审听仍待完成。

本轮使用 golden_hook_v11_manual_sandbox.json，与正常第三关进度分开。测试结束已关闭程序，并恢复测试前的声音偏好状态。测试前无该偏好文件，测试创建的文件已清理。原先游戏进度未被重开。
