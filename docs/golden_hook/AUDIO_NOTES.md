# V1.1 音频实现与验收边界

81 个稳定对白 ID 的离线 WAV 由五个独立中文神经音色生成，正式流程播放其中 57 句。全部注册语音 447.48 秒，活跃剪辑约 293.90 秒；24 个冗余说明 ID 保留文件和注册关系，移出必经播放或放入可选文字档案。逐句理由见 DIALOGUE_EDIT_V1_1.md。角色口型采用正式 WAV 的 25 Hz RMS 包络。

五种声线与三句试听见 VOICE_CASTING_REPORT.md；来源/参数/文件哈希见 NEURAL_VOICE_PROVENANCE.json。不是同一个 SAPI 音色改变速度。没有真人声音克隆，也没有付费账户或 API 费用。生成工具与合成人声的供应商使用条件不能混作同一份开源许可。

配乐由原创 MIDI 编排经 GeneralUser GS 采样乐器和 FluidSynth 渲染为六段 83–124 秒音乐，包含低音大提琴、钢琴/尼龙弦、弦乐与木管/圆号层。详见 MUSIC_MANIFEST.md。音乐不是旧 48 秒正弦合成循环调大音量。

AudioDirector 只有一个 BGM 播放器，切换先淡出再淡入。对白时音乐相对增益降到 20%；秘密与临终阶段淡出音乐，留下对话、环境和静默。池塘与营火采用四个 AudioStreamPlayer3D 声源；全局风、事件音效与音乐分别处理。音乐/音效/配音三个音量档位单独保存。

实际 Windows 全流程录屏包含运行时混音，同时导出音轨供试听。可解码、峰值正常、RMS 或声线名称不同，都不能代替人对断句、重音、年龄感、情绪和音乐叙事关系的听觉判断。本轮尚无独立真人审听签核，不能把这些项目标为正式配音/配乐验收通过。
