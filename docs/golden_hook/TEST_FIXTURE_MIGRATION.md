# 第一关旧测试夹具迁移记录

收到的 V4.1.3 发布包内第一关已是 V3.3，当前游戏会实际等待阿木走到另一端，然后 npc_ready→lifting→carry，并先 lowering 再安装。此前 V2 测试直接在备料侧调用 interact 后断言已搬运，且没有配置 reload 动作。旧回归还尝试调用已退役数字重建尾声的 ready_to_finish。

首次照跑旧夹具得到 repair 15 个失败、recovery 3 个失败；对应原测试文本保存在 legacy_test_fixtures，原始失败日志及汇总在交付 Test_Records/V1_1/Before_Legacy_Fixture_Adaptation。这些失败没有通过把游戏改回即时抬板来消除。

本轮仅更新测试夹具：使用公开 pickup_position 站位，等待实际 join、lifting 和 lowering；验证抬起前不能算持板；补齐用于模块测试的 reload/aiming/sound 接口；保留两处缺口、真实碰撞、两轴对齐、固定、检查、唯一木板所有权、失败恢复的断言。旧 modern 存档测试改为构造完整旧进度并验证它迁移到已完成章节。

更新后的 repair 49 条断言与 recovery 41 条断言通过。第一关 Windows 输入回放也实际跑完选料、队友到位、协同搬运、两处铺板、铁索协作和出口，不依靠夹具取代通关验证。第三关原有 450 条检查保留；不是为了减少失败而删减第三关验收要求。
