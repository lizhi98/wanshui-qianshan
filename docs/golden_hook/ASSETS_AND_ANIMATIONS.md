# V1.1 美术与动画实装

人物沿用 V4.1.3 的 MPFB/MakeHuman 53 骨架与 43 个动画片段。`character_visual.gd` 仅增加可选模型路径入口；第一、二关的默认模型路径保持原值。第三关通过自己的角色适配器复用步行、跑步、脚底接触和骨骼覆盖规范。

小梁与小石保留成熟角色基底；阿青在 Blender 中修改下颌、颧骨和鼻部并穿独立靛灰制服、软帽与工具袋；老班长修改脸颊、下颌和眼睑，增加灰发、灰眉和皮肤老化表现。模型与 43 段动画按同名骨骼重接，不能只导出无动画的模型覆盖正式 GLB。

坐下采用 Sitting_Enter→Sitting_Idle，起身采用 Sitting_Exit 后再走路。第三关 NPC 使用单一 CharacterBody3D 物理根节点、加减速和有限转向。手指/手掌 CCD、脚底接触 IK 只在交互所需时覆盖，退出后清空约束。钓竿、碗、针/钩、汤勺和布包均提供实际接触点。

老班长倒下采用 Death01 的受控过渡，加上靠近身体的折臂、头部卷毯支撑和最终静止姿态。恢复倒地存档立即采样最终姿态，避免重新站起或重复倒下。牺牲后冻结普通待机、呼吸和头部动作；正面、侧面、俯视截图用于检查，并不等同于完整真人动作验收。

湿地采用带自然起伏的地形网格、共享不规则岸线、PBR 草地/湿泥混合材质和分区生境。近景/中景采用合法 CC0 扫描植物与模型 LOD，远景采用实例化简化植被；不在泥区、沼泽、主路径和营地均匀撒草。沿岸新增原创曲茎、折叶芦苇模型，远山与近地形逐米共享交界顶点。

营地新增布顶、麻绳、缝线粮袋、带扣布包、卷毯、搪瓷锅和空心木勺。核心鱼钩是同一枚针的连续管网格弯曲，布包具有 Wrapped 形态键；不是以获得道具提示代替实际制作和收存。鱼为带鳃、鳍、眼和独立尾鳍节点的原创 GLB，收线与离水时有可见身体运动。

仍存在的美术边界：整体人物和部分铺垫/休息物件保留独立游戏的简化造型；湿地远山轮廓和地面材质仍能辨认重复。水面采用实时着色与波纹/水花反馈，没有完整流体仿真。当前结果不宣称已经达到高端写实独立游戏的最终美术标准。
