# V1.1 已知问题与尚未完成的验收

本轮交付是可编辑、可导出、可连续通关的 V1.1 重制评审版本。以下内容没有被改写为“已正式验收”。

| 项目 | 当前状态与实际影响 |
|---|---|
| 自然中文与情绪表演 | 已真正使用五种独立中文神经音色，全部离线播放，已交十五句样本与五组试听。尚无独立真人对自然度、年龄感、临终气息和情绪进行签核；Edge 工具只有韵律控制，不能等同完整的情绪导演模型或真人表演。 |
| 音乐感染力和真实混音审听 | 六段原创 MIDI/采样乐器配乐、剧情静默和声音分轨已接入，实际 Windows 音轨已录制。峰值、解码和自动压低音乐检查不能代替人对对白遮盖、音乐适配和情感的审听。 |
| 人物与场景的最终美术 | 阿青/老班长已修改模型，湿地与营地新增合法扫描资产、PBR 与原创道具。人物仍带简化造型，老年面容尚非高精度扫描脸；手指握细针、袖口与器具近景仍有生硬处；部分坐垫/铺垫保留简单几何。不能宣称已达到高端写实独立游戏的最终水准。 |
| 湿地表现 | 地面有起伏与湿泥变化，岸线不规则，近/中景植物分生境布置并有 LOD。远山仍可见简化轮廓和材质重复，远景草叶有闪烁，水面仍是着色波纹而非流体模拟。 |
| 第二关原始创作工程 | 本地尚未找到原始源码/创作文件。本轮使用用户自己的 V4.1.3 包恢复出可运行基础，145 份脚本和 442 项资源转换成功，194 项有损；未恢复的第二关原始 Blender 文件、未打包测试和开发历史仍缺失。 |
| 退出时插件资源释放 | 三关按钮导航检查通过后，退出日志仍记录 Dialogue Manager 相关 19 个脚本资源未释放。完整第一关输入回放未出现该项退出错误；这是尚需清理的退出生命周期问题，不把它写作零错误。原始 V4.1.3 冒烟退出也有两项音频资源残留，不能混作同一问题。 |
| 独立真人试玩与桌面 UI | 解锁后已用 Sky 补测章节菜单、分项音量、重启设置记忆、全屏/窗口及修正版 Esc 暂停/继续。工具的瞬时 W 不作为持续行走验收，持续逻辑输入由场景检查和完整回放覆盖；独立真人盲测与首玩时长仍待验收。 |
| 跨设备性能 | 本机为 RTX 4060 Laptop / Vulkan Forward+。已检查 720p/1080p 布局并给出固定机位采样；没有在集显、低配显卡和其他 Windows 机器完成全流程。MovieWriter 固定 24 FPS 不是最低帧率承诺。 |
| 服务音频与文学改编的公开发行记录 | 神经语音不是 CC0 资产，未把工具开源许可当作供应商人声输出许可。当前是按任务生成的本地试听交付，公开发行用途的适用条款与文学改编授权仍需项目方记录；没有替用户进行公开发布。 |
| 检查点的取舍 | 保存实际完成的物品事务和 NPC 路径状态。未结束的抛竿重回准备，加热/弯钩可重做，煮汤重新有限等待；不逐帧恢复鱼体与布料物理。已获鱼、唯一鱼钩和已分汤不重复消耗/领取。 |
| 1936 年终章 | 当前是三章统一入口与历史路线档案，没有把档案页面冒充新的 3D 会师关卡。 |
