# V1.1 剧情操作与镜头

22 个故事步骤继续使用事务式进度与唯一物品标识。完整流程为营地查找食物→发现鱼→收集针/线/枝→协作加热弯钩系线装竿→第一次两尾捕鱼→煮汤分汤→跟随老班长并观察鱼骨→面对面理解秘密→边走边说的行军→发现并协助老班长→最后一次捕鱼煮汤→递汤与告别→拾钩、裹布、收入衣袋→与战友继续前行和纪念字幕。

针与钩共用同一实例/唯一 ID `grassland_needle_01`。制作时形态和热色连续变化；鱼线系到钩眼，钓竿安装、鱼嘴挂钩、最终取回和包裹均沿用这件物品。鱼、鱼汤和纪念物只在规则确认后计入，不能重复领取。

秘密分为先跟随、侧后观察同一只碗内草根与鱼骨、再对话三个部分。关键理解的提交发生在对话结束后，避免中途返回菜单把未看完的秘密误存为已进入行军。行军对白允许继续移动，其他重要近景收起任务面板。

临终以受控倒下、支撑头部、队友安全站位、实际递汤、最后对白与四秒静默完成。结尾让同一枚锈钩在布上被包住、移到贴身口袋，人物起身、队伍实际走向远景，再出现纪念字幕和章节结算。
