# V2.0 Playable Campaign Implementation Plan

**Goal:** Deliver a separate, runnable V2.0 that reduces compulsory dialogue by at least 70% and replaces passive progression with reconnaissance, cover coordination, two interactive repairs, fair chain crises, a final relay and structural reconstruction.

**Architecture:** Keep the 2026-10-24 delivery unchanged. The isolated `LongMarch_LudingBridge_V2` checkout starts at `f0c0611`; original mechanisms and scenes stay available for regression. Extend the existing mission through `game/v2/campaign.gd` and focused controllers. Each controller owns its scene props and event conditions and exposes `setup/start/tick/interact/status/snapshot/stop/completed`; the root exclusively advances chapters and restores input.

**Tech stack:** Godot 4.6 standard, GDScript, existing MPFB humans/53-bone clips, Dialogue Manager, existing PBR environment/audio. No new asset dependency.

## Constraints

- Reliability > meaningful play > story events > controls > visual polish > decoration.
- Previous project, Windows EXE, source ZIP and delivery remain intact.
- 20–30 minutes is a first-play design target, not a timer or invented measurement.
- Every main completion comes from a real action; input replays cannot set tasks, damage enemies directly or teleport the player.
- Historical fictional boundary, 78m artistic bridge and 1935–2026=91 years stay explicit.
- Ordinary cues remain mobile and bounded; cinematic events are short and skippable.

## Shared controller contract

```gdscript
signal completed(result: Dictionary)
var mission
func setup(m): mission=m
func start(state: Dictionary={}): pass
func tick(delta: float): pass
func interact(): pass
func status()->Dictionary:
    return {"objective":"", "hint":"", "detail":"", "progress":0.0, "waypoint":Vector3.INF}
func snapshot()->Dictionary: return {}
func stop(): pass
```

Only the root connects `completed` to a matching current chapter. A stale callback or repeated event cannot skip a chapter. Controller snapshots normalize unsafe carrying/climbing to a nearby genuine safe anchor while retaining completed work.
