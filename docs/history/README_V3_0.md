# 飞夺泸定桥 · V3.0

直接运行 Windows 包中的 `FeiDuo_LudingBridge_V3.exe`。音频和资源已内嵌，游戏运行不需要联网、Python 或语音模型。

## 本次体验调整

- 默认任务卡为 720p 下 16px 标题、13px 操作提示，约占屏幕 3.6%；背景透明度 62%。按住 Tab 才展开详细教程。
- 移除巨大目标光柱、悬浮目标黑框和重复提示横幅，使用小地面光圈、细方向条。瞄准时敌人只有小菱形标记。
- 字幕为底部半透明小条。镜头靠近身体时角色淡出，桥头屋顶参与镜头避障。
- 默认快捷铺板：选材后自动备料，E 呼叫阿木，WASD 两人搬运，到缺口 E 放下并自动固定。设置中可开启原来的精细修桥。
- 修桥后续战斗持续进行，战友分批上桥，在未修复缺口等候；通道修好后继续通过。队列使用固定五人池，不无限创建角色。
- 可随时右键放下搬运中的木板，瞄准、射击对岸敌人进行掩护。松开右键，回木板端部按 E，继续搬同一块板。
- 敌方未被压制时，桥上战友可能中弹、失足并坠河；成功掩护能避免相应伤亡。演出无血腥，不会强制每次都牺牲。
- 使用中文男性合成配音，并为各句设置语境、情绪和语义停顿指令。不是演员录音，也没有克隆真人声线。

## 操作

| 操作 | 按键 |
|---|---|
| 移动 / 奔跑 / 跳跃 | WASD / Shift / 空格 |
| 交互、呼叫搬板、放板 | E |
| 放下搬板并瞄准 / 射击 | 右键 / 左键 |
| 装填 | 瞄准时 R；掩护章节也可直接 R |
| 取消搬板，回备料点重试 | 不瞄准时 R |
| 观察 / 转移信号 | F / Q |
| 临时展开完整教程 | 按住 Tab |
| 暂停 | Esc |

快捷铺板省略反复绑扎对齐，观察、掩护转移、攀索与尾声结构组装仍保留。中断搬运后读取检查点会回安全备料状态；正常游戏中右键放下的木板可原地续搬。旧版存档首次运行时尝试复制到新标题的数据目录，旧文件不覆盖。

## 开发与验证

Godot 4.6，默认入口 `game/v2/main.tscn`。代码目录沿用以保留兼容关系；当前产品名为《飞夺泸定桥》。先前 README 和测试报告只作版本历史。

- 新增战斗池与伤亡逻辑：`game/v2/assault.gd`
- 紧凑提示：`game/v2/hud.gd`、`game/v2/guidance.gd`
- 快捷铺板与放下续搬：`game/v2/repair.gd`
- 战斗检查：`tests/v3/assault_checks.gd`
- 提示与字幕检查：`tests/v2/guidance_checks.gd`
- 实际输入通关回放：启动参数 `-- --verify-replay --showcase --assault-demo`
- 配音再生成：`tools/Generate_Expressive_Voices.py --model-dir <模型目录>`，需要单独安装依赖和下载 Qwen3-TTS 1.7B CustomVoice；模型不随游戏分发。

桥长 78 米、人物、敌方火力部署与伤亡演出为玩法改编。桥上角色数量和受击次数不是史实伤亡统计，不能据此识别真实烈士。原有史料与模型、服装、音乐等授权说明保留在 `docs/`、`licenses/`。
