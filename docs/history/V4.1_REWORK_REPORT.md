# V4.1《丰碑·雪线之上》重制报告

## 版本保护与复用

从 V4.0 完整源码包建立独立 `LongMarch_V4_1`；V4.0 的 Source 与 Windows 包已备份并核验 CRC/SHA256。没有覆盖 V4.0 或原 V3.3 工作目录。旧雪山保留 `game/snow/main.tscn` 和原输入回放；桥关仍为 `game/v2/main.tscn`。章节菜单第二关指向新 `game/memorial/main.tscn`。

直接复用原角色控制、相机球形避障、射击、中文 HUD、AnimationTree、53骨骼、手臂/腿部 IK、天气、原子存档及音乐双通道。旧雪山初始化仅增加默认行为不变的脚本工厂，原移动和相机没有重新开发。新版独立存档及任务流程，旧存档不迁移为新版故事。

## 文学主题如何进入操作

| 六幕 | 实际玩家行为及叙事作用 |
|---|---|
| 最后一批棉衣 | F 查看三包衣物，E 取物，抱着包裹走向人物，进行交接。小田从发抖变为穿棉衣；老赵收到衣物；许成已经有棉衣，将最后一包让给阿木。包裹在手中可见，交接过程中有转移，库存、人物外观及持物状态同步提交 |
| 漫长的队伍 | 随队上山，经过不同速度和负重的行军人员。枝石堵住道路时队伍停下，玩家使用推开动作清路，物体碰撞移除后继续前进。途中对白自然发生，不每次弹对话框 |
| 风雪中的行军 | 真实风力改变速度；岩后减轻风力，观察标记后到安全处 Q 指引后方队伍。小田提到刚领到的棉衣，在同一个人物和衣物上回应第一幕 |
| 沿来路寻找 | 清点后返回山路，观察与老战士挎包相同的扎带和足迹。附近人群减少、队伍向前远去，风雪和音乐变弱。玩家主动找到背风处的人影 |
| 岩壁边的人影 | E 蹲下查看，随后 F 查看湿透的衣物和打开的记录；周班长实际沿来路走到现场。调查对白结束后才开始身份揭晓，音乐淡出、保留环境声。身份不在前期任务标题中出现。一次 E 完成慢起、保持、放下的敬礼，同伴同步敬礼，没有QTE或积分 |
| 继续前进 | 玩家重新回到队伍，仍能看到自己发出的棉衣。返队段采用较近的开阔山口，避免重做 V4.0 的最后长距离跑酷。镜头拉远展示仍在前进的队列，最后给出文学与历史说明，而非敌人或物品得分 |

军需老战士是营地中的同一实体，实际沿山路走到背风处，再保持坐姿。识别特征为旧帽补丁、褐色补丁挎包、单薄制服。没有在寻人时临时生成另一个外观相似的尸体。后半段没有流血、死亡震屏或煽情积分界面。

## 动作、镜头与输入

取衣复用 PickUp_Table，清路复用 Push_Loop，检查复用 Fixing_Kneeling，坐姿复用 Sitting_Idle 并调整根部与脚部接地；敬礼用已有手臂和腿部 IK 渐变完成。老战士坐姿在稳定后冻结；肩头和帽顶有积雪，移除厚重行军背包，保留识别用的挎包。棉衣用随骨骼移动的加厚衣层表现，没有宣称制作新的高精人体。

动作期间锁定移动，保留适当视角；暂停和读档不会解除未完成动作的锁。中途存档保留动作进度，交接只提交一次。镜头使用平滑过渡和地形射线检查，检查、揭晓及敬礼保持稳定。开场、山道队列、坐姿近景、敬礼和结尾均有实际渲染检查。

## 脚印与环境的具体改动

原蓝灰矩形来自 `game/snow/world.gd` 的 PlaneMesh。本版将新旧雪山的足迹替换为 `game/memorial/footprints.gd`，使用有透明边缘、鞋跟和鞋腰的左右鞋底贴花及凹陷法线。骨骼脚部由下降转为落脚时生成，静止不生成，射线获取落点和法线，拒绝扫描岩石碰撞，雪地/泥地分别选材质。最多160个贴花，动态印迹按年龄和距离淡出，NPC只在玩家附近少量生成。导航线索不再用蓝色块代替。

新版连续山体缓存位于 `assets/memorial/terrain`，旧缓存独立保留。扩大路面到山坡的过渡范围，加入不规则路宽、踩实区域、三尺度岩石纹理、层理与风积雪。六片宽尺度远景替换原重叠小山片，修复了高处可见的破碎三角片。营地增加衣物、账册、支架和布棚；沿路补充碎石。按剧情调节光照、风雪和远景清晰度，未把原桥关调白作为雪山。

## 队伍规模与性能

配置为8名近景骨骼 NPC、24名中景关节人物、48名远景实例人物，共80个队伍角色，玩家另计。中远景没有逐人刚体或完整AI；远景八组 MultiMesh 共用网格。各人速度、起始动作、偏移与停顿有差别。近景模型75米外不绘制，45米外降低动画更新频率。实际镜头人数受地形遮挡和视锥影响，不能将80人说成同框可见人数。

本机720p三处实时夹具，每处预热1.5秒再采样4秒，帧间隔均值换算约47/75/84 FPS，P95帧间隔约33.5/18.1/16.6毫秒。这是本机短场景测试，不能替代完整关卡或其他硬件性能保证。数据见测试证据。完整输入回放曾记录56名中远景对象位于镜头视锥中，视锥计数不包含遮挡判断；最终视频另存实际数据。

## 声音与音乐

38条逐句导演的合成男声；林川 Dylan、阿木 Eric、周班长 Uncle_Fu 保持原声线。小田使用 Eric、许成使用 Dylan，按场景区分情绪。字幕由同一音频队列驱动；按句配置音量和句后停顿。音频表与替换接口见 `V4.1_AUDIO_DIRECTOR.md`。

六段原创器乐分别对应营地、上山、风雪、寻找、丰碑、继续前进，支持交叉淡化、对白压低音乐、接近人物时淡出及揭晓静音。风声独立保留，可分别调节音乐和环境音。进入揭晓前先等待调查对白结束，避免关键台词挤压留白。音乐未采样电影或商业游戏。

关键演出另作实机修正：周班长必须沿路走到并停稳后才触发揭晓，主动转向老战士；检查、揭晓和敬礼镜头改到人物右前方，避免玩家和周班长遮住坐着的人物。镜头继续使用平滑插值与地形遮挡查询。

## 实际验收与边界

最终 Windows 发布程序完整录像：8分08秒，1280×720、30fps，90 PASS、0 FAIL；三包棉衣真实交付，7名同伴到达，老战士留在山上。37次字幕队列事件均有配音且播放结束，揭晓期间累计7.00秒音乐留白。完整MP4解码无错误，音频峰值-1.2dBFS、均值-25.4dBFS。另附48秒片段。视频所用EXE与Windows压缩包程序SHA256一致：`755fe63191f59d609cacb4ad38356c6e3aba370c1e7cace3d5ed074248e93c11`。

单项和完整输入日志见 `V4.1_TEST_REPORT.md`。本版仍为风格化写实，没有专业面部表演、指尖级动作捕捉、复杂雪面形变或商业3A角色精度；中远景人物明确为低成本表现，不能近看当成完整主角模型。配音仍有合成音的限制，导演表可用于后续真人录音替换。部分程序化岩面仍有材质重复，脚印采用法线假凹陷，没有改变地形网格。

远景队列修正了头颈、腰腿连接空隙，将帽子改为扁圆柱轮廓；7项连接检查覆盖16个步态相位。最终性能采样为关闭垂直同步、无并行录像的720p短夹具，仍不代表全程或其他硬件保证。
