# 飞夺泸定桥 · V3.2

运行 `Windows/FeiDuo_LudingBridge_V3_2.exe`。游戏资源、男声对白、音乐和音效已内嵌，无需联网或安装 Python。

本版针对录屏里的动作抽动、瞄准穿模、桥头敌人混在战友身边，以及场景粗糙作出修复：

- 队友跑动不再因一次射击机会瞬间转身；等候缺口时保持稳定站姿，掩护动作有持续时间，起步与转向按时间平滑。
- 镜头使用带半径的碰撞检测，覆盖铁索、栏杆和主要岩石；桥边会选择桥内侧肩位。镜头收回后再缓慢伸出，减少反复弹跳。
- 镜头附近遮挡瞄准的队友会从该镜头中隐藏，离开遮挡范围后恢复；不再出现占满画面的半透明脸部。队友仍留在场景中，行动和任务照常进行。
- 移除桥头敌人定时复活。进入夺取桥头后的接应阶段，前景守军倒下、远景敌军撤出演出，双方炮击停止；已击倒敌人的血量写入检查点，读档不会重新出现。
- 地形网格加密并平滑法线，加入岩壁法线、潮湿河岸和材质变化；补充扫描岩石、屋瓦、窗框、台阶、火炮轮辐、铁轮箍与炮口细节，提升铁链圆滑度。河面减轻规则白纹和刺眼高光；高画质使用四倍 MSAA。

WASD 移动，Shift 奔跑，E 交互或放板，右键放下木板并瞄准，左键射击，R 装填；松开右键后到板端 E 续搬。F 观察，Q 发信号，Tab 展开教程，Esc 暂停。攀索时 W/S 前后、A/D 调平衡。若机器性能不足，可在“操作与画质”切换性能模式。

保留 V3.1 的配乐、三种合成中文男声、两岸 NPC 炮组、战友过桥和非血腥牺牲表现。对白为合成语音，并非真人演员录音。人物、炮组部署、兵力数量及 78 米跨度为玩法改编。场景细化采用现有授权扫描模型和 PBR 素材；这是本项目的画面提升，尚未达到 3A 制作规格。

旧 V3.1 检查点可继续读取；原程序与旧交付不被覆盖。Godot 4.6 入口仍为 `game/v2/main.tscn`。新环境模块为 `game/v32/environment_detail.gd`，针对性检查在 `tests/v32/`。

完整通关视频来自交付 EXE 的实际输入回放，含辅助镜头朝向及炮组展示镜头；任务通过正常操作推进。美术、音色、角色等授权参见 `licenses/` 和原工程资产说明。V3.1 原创配乐说明见 `README_V3_1.md`。
