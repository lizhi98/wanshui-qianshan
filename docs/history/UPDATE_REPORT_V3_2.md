# V3.2 修改与验证说明

## 动作抽动

用户短录屏呈现了队友在跑步、蹲姿和举枪之间快速切换、朝向突然改变的问题。原推进逻辑会在移动时触发射击并立即朝向敌人，受阻时又直接切换蹲姿。本版将开火限定在稳定的掩护姿态，移除射击函数对人物朝向的瞬时写入；受阻等候增加最短保持时间，掩护采用持续窗口，转向限速，起步加速，循环角色重生时重置物理插值。

保留按实际位移换抓的攀索接触：停下时脚步周期停止，双手交替支撑。针对检查验证了射击机会不会让跑动角色突然转身、受阻队伍不会高频蹲起，以及攀索手部支撑与停止稳定性。

## 瞄准视野

旧相机只检测世界碰撞层，未覆盖铁索栏杆；单根射线也不能代表近裁剪面的体积。镜头偏肩使右侧上桥位置更容易进入铁链。旧人物透明处理仍会留下覆盖画面的面部。

本版使用半径 0.22 米的球形扫掠，检测世界、桥栏和主要岩石的相机碰撞层；上层铁索加相机专用碰撞代理，避免改变角色行走。桥边选择朝内肩位，遇物体立即缩回、离开后平滑伸出。靠近镜头的遮挡角色通过渲染层排除，并保持短暂滞回，离开后恢复，替代大面积半透明。

实机图形检查覆盖右侧铁索持右键瞄准、相机体积不与栏杆相交、背后障碍触发缩回、队友不覆盖瞄准和恢复可见性。检查日志、截图随交付提供。

## 敌人状态

移除主线守军被击倒后二十二秒的循环复活。接应阶段的桥头占领事件统一清除主线威胁和背景敌军演出，释放在途炮弹并停止继续炮击，避免战友在敌人枪口旁平静等候。尸体保留非血腥倒地表现。检查点新增守军血量和桥头占领字段，校验字段范围，同时兼容旧检查点。

## 场景细化及范围

地形从 120×76 加密至 240×152，生成平滑法线和切线，增加地形法线、粗糙度和潮湿岸线；增加 44 组已有授权扫描岩石，补充草丛、木窗框、屋檐、台阶、瓦片纹理。铁链由明显多边形轮廓改为更圆滑的环。火炮增加木轮辐、铁轮箍、炮管箍和暗色炮口，普通盒体采用倒角网格。水面采用叠加流动波纹，减轻重复白纹与过亮高光，高画质提高抗锯齿。

参考了 Epic 官方关于高精度扫描素材与场景细节组织的资料：[Valley of the Ancient](https://dev.epicgames.com/documentation/unreal-engine/valley-of-the-ancient-sample-game-for-unreal-engine?lang=en-US)、[Nanite 技术介绍](https://www.unrealengine.com/blog/understanding-nanite---unreal-engine-5-s-new-virtualized-geometry-system)。本工程仍使用 Godot，不采用 Nanite 或 Lumen；没有把技术参考中的演示资源打包进来。当前改动无法替代专业团队制作的完整 3A 场景与角色资产。

## 验证交付

通过针对性动作、相机、占领与存档测试，并回归原有攀索、两岸交火、受击坠河、协作搬板、章节恢复、提示和完整输入通关流程。部分旧测试退出时仍有 Godot 资源回收警告，日志保留；运行中的脚本异常及图形录像另行核验。最终 EXE、源码、完整录像、测试证据及文件哈希分别交付，旧版本保留。
