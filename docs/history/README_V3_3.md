# 飞夺泸定桥 · V3.3

运行 `Windows/FeiDuo_LudingBridge_V3_3.exe`。人物、场景、对白、音乐与音效已内嵌，无需联网。

这次调整围绕“突击在前，铺板跟进”：

- 新增两名前方掩护战士，先沿左右铁索越过缺板处，在前面的完整桥面交火。玩家与阿木随后搬板，后方援兵数量收敛，避免围住铺板组。若掩护组尚未就位，搬板前进会在安全位置短暂等候。
- 首处铺板时，前方掩护战士会遭敌军射击，中弹失去平衡并坠河；阿木发出警告，林川回应“不能辜负同志的牺牲，冲啊！”。这是一次性的剧情调度，检查点会记录，读档不会反复触发。表现不含血腥细节。
- 新录三句合成中文男声，分别对应周班长的分工命令、阿木的警告和林川的回应。继续沿用三种角色声线和逐句表演指令，并非真人演员录音。
- 删除玩家流程中的“2026 数字结构重建”：抬起桥亭横档、接应战友、确认通道之后直接结算。旧版尾声检查点会迁移到新结局，不再打开组装界面。
- 更换旧尖三角草丛，加入多节弯曲草叶、带叶脉与茎的蕨类、分枝灌木、岸边莎草与枯枝，按区域成簇分布并随风摆动。人物增加粗棉布质感、磨损、背包织带与扣环，炮手改为稳定装填姿态。

WASD 移动，Shift 奔跑，E 交互/铺板；必要时右键放板并瞄准，左键射击，R 装填。松开右键，在板端 E 续搬。F 观察，Q 发信号，Tab 展开教程，Esc 暂停。攀索时 W/S 前后、A/D 保持平衡。性能不足可在设置里切换性能模式，植被密度随之降低。

战斗分工、人物、炮组与牺牲情节均为艺术化改编，不声称复原某位真实烈士的具体经历。植被参考大型游戏对草、蕨、灌木和环境层次的组织方式，使用本工程新写的几何与着色器，没有使用《最后生还者》的模型或贴图；当前仍是本项目的简化美术规格。

Godot 4.6 入口为 `game/v2/main.tscn`。前方掩护、植被和人物材质模块位于 `game/v33/`，针对性检查位于 `tests/v33/`。历史版本源码留作记录，当前入口不运行数字重建模块。通关视频使用交付 EXE 的实际输入回放，包含辅助镜头与炮组展示镜头，任务正常推进。
