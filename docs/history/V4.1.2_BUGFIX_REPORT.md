## 高潮实际流程
警卫员报告 → 指挥员赶到 → 查看单衣 → “把军需处长给我叫来！” → 对物资追问 → 无人回应 → 再问 → 警卫迟疑 → “他……就是军需处长。” → 音乐淡出、指挥员震惊和手臂垂下 → 短句回应 → 玩家一次E、指挥员与众人缓慢敬礼 → 返回队伍。

指挥员沿用同源完整人物，深色衣料、高领与皮质图袋区分身份，移除普通背包；没有以新资产包冒充模型重制。面部以头朝向、呼吸/嘴部运动配合镜头，细致眼神及老年皱纹仍不足。近景背景由12个同源完整骨骼槽位承担，超过容量的近处简化替身隐藏；中远景保留24/48配置。两名新实体使主角外的剧情近景角色为10名，不能将72名低成本队列都称为高精人物。
