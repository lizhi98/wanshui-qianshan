# 万水千山 V4.1.1 修正版

Windows包解压后运行 WanShuiQianShan_V4_1_1.exe，选择第二关。WASD移动，鼠标视角，F观察，E交接/检查/敬礼，Q发信号，Esc暂停。

本版针对六项试玩反馈修正，保留泸定桥和旧雪山入口。新版存档独立为memorial_campaign_v411.json。源码入口project.godot；Godot4.6；Run_Memorial_Tests.cmd执行新版套件。旧V4.1报告保留作历史记录，当前结果请以V4.1.1文件为准。

配音和音乐沿用已交付的授权资源，文学主题为李本深《丰碑》，公开使用前需确认改编权利。配音为合成男声。
