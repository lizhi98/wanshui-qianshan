# V3.3 修改记录

截图中的首要问题是桥面援兵与铺板组共用“等待缺口修好”的路径，所以所有战友都停在玩家身后。新增前方掩护组具有独立的铁索路线：先越过缺口，再在完整桥面掩护，玩家与阿木搬运木板。铁索两侧分别使用对应手脚接触方向，前方掩护仍未就位时在安全位置自动等候。普通后续援兵在修桥阶段限制为三名，通路开放后继续推进。

牺牲事件只在首处缺口、玩家正在搬板、前方掩护已就位且敌军仍存在时触发。弹道从敌军枪口到掩护战士，中弹后先失衡再向桥外坠落，最后出现水花。事件随后排入阿木的警告和林川的回应，三句新增对白均使用离线 Qwen3-TTS 生成并记录声线、表演指令、时长与音频哈希。检查点保存事件及回应状态，恢复时不会重放已发生的牺牲。

章节顺序改为山路、侦察、压制、铺板、攀索、接应、完成。数字重建不再创建玩家操作控件，不再加载它的镜头和结构场景。兼容旧版 modern 检查点并转入新结算，旧源码保留为历史资料。通关回放也同步删除全部采集、分类和组装操作。

原草丛只有六片直三角形。本版替换为多段弯曲叶片，加入具有弯曲中脊、叶脉、茎与分枝的蕨类、灌木，按疏密斑块散布，加入岸边高草和枯枝。风只影响叶片上部，根部保持在地面；实例按两岸分组、设置显示距离，性能模式降低显示实例数量。人物原骨骼与脸部纹理保留，衣料使用细织纹、污渍和低反光材质，背包补充织带、扣环；炮组成员使用稳定蹲姿与靠近炮架的手部接触。

美术参考查阅了 [Naughty Dog 官方环境摄影集](https://www.naughtydog.com/blog/photo_mode_collection_breathtaking_environments) 以及 [《最后生还者 Part I》环境纹理作者的场景作品说明](https://katelynjohnson.artstation.com/projects/4XrDdl)。本版据此选择分层植被、材质变化和场景布置方向，几何与着色器为本工程实现，没有提取商业游戏资产，也没有实现同等级的完整制作管线。

验证包括前方掩护路线、射击、铺板时牺牲与回应、事件状态恢复、直接结局和旧尾声检查点迁移，以及原有配音串行播放、协作搬板、攀索、相机遮挡、敌人状态恢复和完整输入通关。录像由最终发布程序生成，程序哈希、完整日志、截图与压缩包校验随交付提供。少量旧检查仍可能在进程退出时报告 Godot 资源回收警告，保留原始日志供核查。
